還不快救主！v0.10.3 房間連線修正版
================================================

本工程要部署成 Render「Web Service」，不是 Static Site。
同一個服務同時提供：
1. 遊戲網頁
2. 房間伺服器
3. WebSocket /ws

【更新既有 Render 服務】
1. 將本資料夾所有檔案覆蓋到 Render 連結的 GitHub 儲存庫根目錄。
2. 提交並推送 GitHub。
3. 等待 Render 自動重新部署；或在 Render 按 Manual Deploy → Deploy latest commit。
4. 部署完成後，重新整理遊戲頁面。首頁「線上對戰」應顯示綠色狀態燈與「伺服器在線」。

【第一次部署】
1. 把本資料夾內所有檔案放到 GitHub 儲存庫根目錄。
2. Render → New → Web Service。
3. 連接該 GitHub 儲存庫。
4. Runtime：Node。
5. Build Command：npm install
6. Start Command：npm start
7. Health Check Path：/health
8. 建立服務並等待部署完成。

也可使用 render.yaml：
Render → New → Blueprint → 選擇本儲存庫。

【房間操作】
1. 兩台手機都開啟同一個 https://xxxx.onrender.com 網址。
2. 雙方按「線上對戰」。
3. 建立者輸入房間代號後按「建立房間」。
4. 加入者輸入相同代號後按「加入房間」。
5. 房間代號接受 1～8 位英文字母或數字，不分大小寫。
6. 雙方進入列隊畫面，各自按「準備」。
7. 雙方都準備後倒數 3 秒開始。

【狀態燈】
- 黃燈：正在檢查或喚醒伺服器。
- 綠燈：伺服器在線或房間已連線。
- 紅燈：連線失敗；點擊「線上對戰」可重試。

【v0.10.3 修正】
- Render 休眠喚醒等待由原本 6 秒改為最長 60 秒健康檢查＋45 秒 WebSocket 連線。
- 建立／加入房間會等待伺服器正式回覆，不再只把指令丟出去就卡住。
- 10 秒內未收到房間回覆會顯示可見錯誤並恢復按鈕。
- 錯誤文字直接顯示在房間視窗，不再藏在戰鬥畫面裡。
- 移除聯機視窗右上角叉號；點擊視窗外暗色區域即可返回。
- 首頁線上對戰按鈕新增伺服器狀態燈與發光效果。

【目前限制】
- 仍是「伺服器排序命令、兩端各自模擬」，尚非完整防作弊權威伺服器。
- 伺服器重啟、部署或休眠會中止房間，暫無斷線重連。
- 房間保存在記憶體；服務重啟後會消失。
