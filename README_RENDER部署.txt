還不快救主！v0.10.58 稀有度配色版

啟動方式
1. 直接開啟 index.html，可進行單機測試。
2. 執行 npm install 後使用 npm start，可啟動本機伺服器與 WebSocket 聯機服務。
3. Render 可依 render.yaml 部署。

本版重點
- 以 v0.10.48 決鬥場前版本為母版，不包含兩軍決鬥系統。
- 每完成第 10、20、30……波後，進入 10 秒麻煩卡三選一。
- 玩家選出的卡牌永久施加於對手；同一張卡可在後續輪次再次取得並累積。
- 未在倒數內選擇時自動選牌；單機 AI 會立即自動選牌。
- 黃巾之亂：對手每波額外出現 1 隻寇。
- 急行：對手怪物速度永久 +10%。
- 難題：對手怪物血量永久 +10%。
- 動物園：對手每波額外出現 1 隻鹿、1 隻野豬、1 隻狼。
- 額外召來的麻煩怪物不提供饅頭與武將經驗，避免反向獎勵受害方。
- 聯機新增 troubleCard 同步指令，聯機協定版本 6。
- 原 v0.10.48 龐統助攻經驗與既有塔防玩法全部保留。

武器頁 UI
- 武器分頁已解除鎖定。
- 頂部顯示本局已選武將，點擊後依武將使用的武器類型自動篩選。
- 再次點擊同一名武將可返回全部相關武器。
- 長按武器卡可查看武器類型、適用武將與未來功能說明。
- 本版僅完成 UI 與資料接口；實際裝備、數值、第二技能與戰場武器圖片替換尚未啟用。
