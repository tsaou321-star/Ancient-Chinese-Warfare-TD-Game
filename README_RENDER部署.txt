還不快救主！v0.10.1 Render 線上對戰測試版
================================================

這一包要部署成 Render「Web Service」，不是 Static Site。
同一個服務會同時提供：
1. 遊戲網頁
2. 房間伺服器
3. WebSocket /ws

【最快部署】
1. 把本資料夾內所有檔案放到 GitHub 儲存庫根目錄。
2. Render → New → Web Service。
3. 連接該 GitHub 儲存庫。
4. Runtime：Node。
5. Build Command：npm install
6. Start Command：npm start
7. Health Check Path：/health
8. 建立服務並等待部署完成。

也可使用 render.yaml：
Render → New → Blueprint → 選擇本儲存庫。

【開始測試】
1. 兩台手機都開啟同一個 https://xxxx.onrender.com 網址。
2. 兩邊先選好四名武將。
3. 玩家一按「線上對戰」→「建立房間」。
4. 把六位房間代碼交給玩家二。
5. 玩家二按「線上對戰」，輸入代碼後按「加入房間」。
6. 雙方都會在自己的手機下半場操作自己；對手顯示在上半場。

伺服器欄位正常情況不用改，遊戲會自動連到目前網址的 wss://.../ws。

【目前完成】
- 建立／加入房間
- 玩家一／玩家二分配
- 雙方相同亂數種子
- 30Hz 同步時鐘
- 徵兵、放置、收回、鏟子技能、投降命令排序同步
- 玩家二鏡像畫面與反向觸控
- 20 秒應用層心跳與伺服器 WebSocket ping
- Render 部署更新時通知客戶端

【目前限制】
- 還是「伺服器排序命令、兩端各自模擬」，不是完整防作弊權威伺服器。
- 伺服器重啟、部署或休眠會中止房間，暫無斷線重連。
- 下一階段需把傷害、怪物、資源、經驗、勝負與快照移到伺服器。
